# 离开 App 后继续接收通知

cetus 用前台服务保持一条到电脑的事件连接，才能在锁屏后收到审批和完成提醒。系统如果把 App 杀掉，这条连接会断。

打开设置里的「离开 App 后继续接收通知」之后，请把 cetus 加入电池优化白名单，并允许后台活动。

## 小米 / Redmi / POCO

设置 → 应用设置 → 应用管理 → cetus → 省电策略 → 无限制。
再打开「自启动」。

## 华为 / 荣耀

设置 → 应用和服务 → 应用启动管理 → cetus → 手动管理，打开「允许自启动」「允许关联启动」「允许后台活动」。

## OPPO / realme / 一加

设置 → 电池 → 更多设置 → 应用耗电管理 → cetus → 允许完全后台行为。
再在应用详情里打开「允许自启动」。

## vivo / iQOO

设置 → 电池 → 后台耗电管理 → cetus → 允许后台高耗电。
再打开「自启动」。

其他品牌在系统设置里搜索「电池优化」或「后台活动」，把 cetus 设为不优化。
