1. 双子节点链 (Dual-Node Link) CORE-LINK

以对角咬合的圆角胶囊构成互联双环，中心带有微光核心。象征手机与电脑终端在局域网/远程中继上的稳固握手，契合 DeepLinks 核心连接语义。

形态: 几何环链 色系: 品牌蓝 & 电光蓝
ACTIVE

2. 极客拓扑 D+L (Deep Resonance) MONOGRAM

将字母 "D" (Deep) 与 "L" (Links) 融合为统一流线。外围是坚实的圆角 D 轮廓，内嵌终端提示符与折线，兼顾工业感与终端开发者审美。

形态: 字符变体 色系: 极客深邃蓝紫
ACTIVE

3. DLP/1 安全中继管道 (Secure Tunnel) PROTOCOL

轨道虚线环绕着45度旋转的安全菱形核，贯穿左右双端光纤节点。直观表达协议中 DLP/1 逐字节加密管道（Pipe）与安全远程连接技术特征。

形态: 轨道透镜 色系: 远端天青与品牌蓝
ACTIVE

4. 液态棱镜折射 (Liquid Prism) BACKDROP

呼应项目 UI 正在推进的“液态玻璃与折射透镜（Backdrop Lens）”系统。两个相互半重叠的圆角矩形，在交相辉映处呈现折射光斑与双端映射。

形态: 液态玻璃半透层 色系: 动态多重透明度
ACTIVE

5. 莫比乌斯无限环 (Infinity Pulse) STREAMING

等宽圆管构成无限平滑闭环，内嵌流动节点。象征 AI 任务持续执行（Streaming）、状态双向同步与不间断会话控制流。

形态: 连续无限拓扑 色系: 渐变全色谱
ACTIVE

6. 终端链扣 (Terminal Anchor) MINIMAL

将控制台 Shell 提示符 `>` 与远程链扣紧密组合在极简深色圆角方盾上。硬核、稳重，极度适合作为 Android 状态栏图标与 Monochrome 单色剪影。

形态: 徽章/终端符 色系: 墨色底版 & 亮蓝
