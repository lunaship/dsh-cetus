# 真机验收清单（维护者执行）

> 用途：把 T01–T46 里**只能在真机上验**的项，整理成一份可以照做的手册。
> 我（云端 agent）无法执行其中的任何一条 —— Android 模拟器在本环境无法开启端口、
> iOS 只能跑模拟器、且没有 Apple 付费账号。**没有做过的事不会被写成做过。**
>
> 目标：**约 30–40 分钟**覆盖 13 条 T 项中的大部分。

## 0. 准备

| 需要 | 说明 |
|---|---|
| 手机（Android 或 iPhone） | 装 `cetus` 的签名包 |
| 电脑（运行 DSH host + 本插件） | 已配好 `dsh-cetus` 插件，host 可启动 |
| 同一局域网 | 真机与电脑在同一 Wi-Fi（远程项另需能上外网） |
| 记录方式 | 截图 + 录屏；**每条都记下手机型号、系统版本、包版本** |

Android 安装包：`.local/release-builds/0.5.0-beta.31-f11f0a08/cetus-android-0.5.0-beta.31-f11f0a08.apk`
（`applicationId=dev.deeplinks`，证书 `38f71adf…2a47`，versionCode 39，v2+v3 双签名）
SHA-256 `7f8d2e7a…cf17d`（见 `ANDROID-RELEASE-EVIDENCE.md` §0）

iOS：需自行从源码构建（`apps/ios/`，Xcode 26.6）。

> **红线**：不要在全局 state 上做冒烟。要隔离时用 `stateDir` 配置覆盖。
> **不要**在真机上调用设备吊销类操作。

## 8. 推送与锁屏（需 Apple 付费账号）→ T31 / T32 / T34

**前提**：配置好 APNs 密钥与推送证书。**没有账号则跳过整组，并在报告里标未验证。**

| 步骤 | 操作 | 预期 |
|---|---|---|
| 8.1 | 触发一次审批 | 锁屏通知到达；**内容是通用文案**（不含命令/文件名/标题原文） |
| 8.2 | 同上，检查通知上**没有**批准动作按钮 | `docs/rfc/0002-push-gateway.md` §8 执行红线第 4 条：「不在通知或 Live Activity 上提供批准按钮」 |
| 8.3 | 任务完成 / 失败各一次 | 各自送达 |
| 8.4 | 有灵动岛的设备：任务进行中 | Live Activity 出现；超过 `staleDate`（最后一次更新 + 15 分钟）后显示为**已离线 + 最后更新时刻**，**不**继续显示为"运行中"，且**不**使用会无限递增的计时 |
| 8.5 | 锁屏上点通知打开已处理/已删除的会话 | 刷新终态或给说明，**不崩溃**、不误操作 |
