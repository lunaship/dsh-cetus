# DeepLinks iOS 设计稿（I1.5a）

放置位置：`apps/ios/docs/design/`。页面编号与 `docs/redesign-v4/design-v4.html` 一致。
这是 **HTML 近似稿**：用来定布局、层级、字号、颜色。真实 Liquid Glass 效果在 I1.5b 用 SwiftUI 模拟器截图验收。

| 文件 | 用途 |

页面：1.2 欢迎、1.3 扫码、2.1 首页、4.1 运行中、4.3 待审批、4.4 回答问题、6.1 改动、6.2 diff、7.1 设置、8.4 锁屏 Live Activity、8.5 灵动岛状态（评审图，非全屏）。

## 设计决定（相对 v4 Android 的变化）

1. **首页**：大标题 + 副标题显示电脑状态（点开切换电脑 / 工作区，对应 2.5）。底部是 iOS 26 邮件式工具栏：玻璃搜索框 + 品牌色“新任务”按钮（`square.and.pencil`，无障碍标签“新任务”）。替代 v4 的浮动“新任务”胶囊。
2. **每屏最多一个品牌实心按钮**。首页的“新任务”占用了它，所以列表里的“允许一次”用浅色着色按钮（`.bordered` + tint），“拒绝 / 回答”用灰色。
3. **审批与提问**：底部决策栏替换输入区，是**一整块玻璃**；里面的命令块、选项列表、按钮全部用**实色**，避免玻璃叠玻璃（执行方案里写的 `.glass` 按钮改为灰色填充按钮）。对话内容淡化到 42% 不透明度。
4. **导航栏**：返回、标题、“+148 −37 / ⋯”都按 iOS 26 规则浮在内容上，右侧多个按钮合成一个玻璃胶囊。顶部用滚动边缘渐隐，不画分隔线。
5. **设置**：系统分组列表，图标统一用强调色、不加彩色底块（只用单一品牌色）。值放右侧（“中文 / 审批、完成 / ¥42.10”），比 v4 的两行副标题更符合 iOS 习惯。
6. **改动 / diff**：范围切换用分段控件；diff 底部是玻璃“上一个 / 下一个” + 品牌色“就这段提问”。
7. **欢迎页**加了“先看看演示”：App 审核员无法配对电脑，必须有演示模式。
8. **扫码页**深浅色相同（相机永远是深色）；手电筒放右上角。
10. **不做 1.4 输入配对码**（沿用 v4 决定），1.2、1.3 只保留“从相册识别 / 从相册选择”。
9. **锁屏 / 灵动岛**：推送只带状态、步数、计时、进度；标题由 App 本地查。命令、文件名不出现在锁屏；任何位置都没有“允许”按钮，只能“打开 App 审批”。

## 颜色

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| AccentColor | `#3F5BD6` | `#8B9DFF` | 文字按钮、图标、选中态 |
| BrandFill | `#3F5BD6` | `#4C66E6`（暂定，待你定） | 品牌实心按钮底色，白字 |
| 状态 | systemOrange / systemGreen / systemRed | 同左（系统自动适配） | 等待、完成、失败；diff 增删 |
| 其余 | 系统语义色（label、secondaryLabel、fill、systemBackground…） | | |

深色 BrandFill 候选（白字对比度 / 对纯黑背景）：`#4F6AEB` 4.57 / 4.59，**`#4C66E6` 4.83 / 4.35（推荐）**，`#4A63E0` 5.06 / 4.15，`#3F5BD6` 5.71 / 3.68。要求：白色 17pt 中粗体 ≥ 4.5:1，按钮对背景 ≥ 3:1。

## 字号（iOS 默认“大”档）

大标题 34 粗、title3 20 中粗、headline 17 中粗、正文 17、subheadline 15、footnote 13、caption 12；代码、路径、命令用等宽字体。实现时一律用动态字体文字样式，不写死字号。

## HTML 稿的局限

- 字体：本机没有苹方 / SF Pro，用的是 Noto Sans SC，真机字形会更紧凑。
- 玻璃是 `backdrop-filter` 近似，没有折射、高光和 iOS 27 的着色调节。
- 图标用 Ionicons 近似 SF Symbols，实现时换成对应的 SF Symbol。
- 只画了 402×874pt（17 Pro）；Pro Max 与 SE 尺寸在 I1.5b 用模拟器截图覆盖。

## 你要做的（I1.5a 验收）

1. 把 PNG 传到 iPhone，用“照片”全屏查看：字号是否舒适、层级是否清楚、一屏信息量是否合适。
2. 手机切到深色模式，全屏看 `brandfill-candidates--dark.png`，从 4 个里选一个。
3. 有修改意见直接按页面编号提（例：“2.1 允许一次改成实心”）。
