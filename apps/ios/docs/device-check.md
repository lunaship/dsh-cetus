## 安装

1. Mac 安装正式版 Xcode，并登录免费个人 Apple ID。
2. iPhone 打开“设置 → 隐私与安全性 → 开发者模式”，然后用数据线连接。
3. 在仓库根目录执行 `xcodegen generate --spec apps/ios/project.yml`。
4. 用 Xcode 打开 `apps/ios/DeepLinks.xcodeproj`，选择 `DeepLinks` scheme 和这台 iPhone。
5. Signing 使用 Automatic 与个人团队。App 标识是 `dev.deeplinks.ios.debug`，三个扩展分别是 `notification-service`、`live-activity`、`share`。
6. 只构建并运行 Debug。免费签名有效期约 7 天；推送、App Group 和 iCloud 钥匙串不在本次范围。
7. 首次打开后到“设置 → 通用 → VPN 与设备管理”信任开发者。

## 局域网冒烟

- **D1 配对**：扫隔离电脑二维码。预期进入首页，不新增第二台同名电脑。
- **D2 同机重配**：先解除配对并回到欢迎页，再用同一台电脑的新二维码配对。预期仍只有一台，不保留旧 token。
- **D3 会话**：首页能看到隔离 host 的会话。
- **D4 流式输出**：打开会话，助手文字逐步出现。
- **D5 发消息**：发送一条不含机密的消息。预期出现在会话里；失败时草稿仍在，不自动重发。
- **D6 审批**：触发一次审批。首页无快照时显示“等你批准”；会话里可“拒绝”或“允许一次”。
- **D7 提问**：触发一次提问。首页显示“等你回答”。多题可“上一题 / 下一题”，可选题才有“跳过”，最后一次提交全部答案。未知类型仍显示“等你处理”。

## 历史遗留

- **D18 本地网络被拒**：首次局域网连接前应看到说明页。拒绝后，诊断或配对失败页给出系统设置入口。打开设置后不删除凭据。
- **D19 切换网络**：Wi-Fi 与蜂窝各切一次。预期重新探测；30 秒内不使用切换前缓存的地址。恢复后会话可重试。
- **D20 卸载重装**：卸载 App，重启 iPhone，再安装。预期回到欢迎页，不自动恢复 token、主机或别名。钥匙串使用 AfterFirstUnlockThisDeviceOnly，且不同步。

## A3 抽查

- **D22 目标**：打开“⋯ → 目标”。编辑、暂停、继续、清空成功后，界面跟随插件状态。请求失败时，原目标阶段和文字保持不变。
- **D23 历史**：消息超过一页时，顶部显示“加载更早消息”。成功后旧消息插入且当前位置不丢；失败时显示“无法加载更早的消息”，原消息和游标保留。
- **D24 附件**：加号里的“文件”只接受 PNG、JPEG、WebP、GIF，最多 4 张，单张不超过 4 MB。其他文件被拒绝。没有裁剪、相机或相册入口。
- **D25 设置**：诊断显示真实检查项。别名只在这台手机变化。模型页使用全局模型列表；余额请求间隔至少 5 分钟。密钥框不回显旧值，保存成功后清空。
- **D26 解除配对**：设备列表里只能确定一个本机 ID 时，成功后删除凭据。回首页、下拉刷新或重新打开 App 后回欢迎页。列表失败、同名多台或空 ID 时不发请求，并显示“没有解除配对，本机凭证仍保留。”

崩溃导出只在 App 已有 MetricKit 报告时出现。导出内容应去掉路径、token 和消息正文；没有报告时不要为了测试制造崩溃。
