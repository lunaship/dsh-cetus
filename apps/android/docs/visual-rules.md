# 视觉规则 v4（不可违反）

> 适用：DeepLinks Android 客户端。页面以 `docs/redesign-v4/design-v4.html` 为准；本文件与设计稿冲突时，以设计稿为准并回头修改本文件。
> 由 `architecture/` 下 6 个测试强制执行，违反就让 `testDebugUnitTest` 失败。

## 1. 唯一方向

**Material 3 组件 + 实底 + 单一品牌色。** 学 Apple 的分层（内容层 / 功能层），不学 Apple 的材质。

- **内容层**：消息、diff、文件、列表。铺在画布上，不加卡片、不加阴影。
- **功能层**：顶栏、状态槽、输入区、决策栏、弹层、对话框。用容器色或画布色实底区分，**不用模糊、半透明、玻璃、渐隐**。
- 外部参考（Apple HIG、Remodex、lody-iOS）只用来回答“怎么分层、怎么排序”，不改变本文件的取值。

## 2. 颜色（只有这些）

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `background` 画布 | `#FFFFFF` | `#121214` | 页面底 |
| `surface1` 容器 | `#F4F5F7` | `#1C1D21` | 输入区、用户气泡、代码块、横幅、当前电脑块 |
| `surface2` 容器强调 | `#E9EBEF` | `#27292E` | 按下态、次要按钮底 |
| `outline` 分隔线 | `#E3E5E9` | `#2D2F35` | 1dp 分隔线、输入框描边 |
| `onSurface` 正文 | `#15171C` | `#ECEDF0` | 标题、正文 |
| `onSurfaceVariant` 次要 | `#555A64` | `#A9ADB6` | 副标题、元信息、过程行 |
| `tertiaryText` 三级 | `#6E737D` | `#8C9099` | 占位符、禁用 |
| `primary` 品牌蓝 | `#3F5BD6` | `#8B9DFF` | 主按钮、链接、选中、进度 |
| `primarySoft` | `#ECEFFC` | `primary` 15% | 选中 chip / 分段底 |
| `wait` 等你 / 风险 | `#B25E0C` | `#E9A35B` | 等你批准、等你回答、完全权限 |
| `ok` 成功 / 增 | `#1F7F4A` | `#62C28E` | 完成、diff 增行 |
| `err` 失败 / 删 | `#C83A30` | `#F07B70` | 失败、diff 删行、危险操作文字 |
| `*Soft` | `#FCF1E5` / `#E6F3EB` / `#FBEAE8` | 对应色 13% | 只用于 diff 行底和状态槽底 |

- 纯黑背景开关：`background` 与 `surface1` 改 `#000000` / `#141416`，其他不变。
- **一个界面最多一个品牌实心按钮。** 状态色只表达状态，不做装饰；子代理、工作区等不按名字配色。
- 不使用动态取色（Material You）。

## 3. 文字

- 系统字体（Roboto + Noto Sans SC）；代码、路径、命令、模型 ID 用等宽。
- 只用 5 档：`26` 首页大标题 / 金额；`17` 页面标题、弹层标题；`15` 正文、列表标题；`13` 副标题、元信息、组头；`12` 角标、时间。
- 字重只用 400 / 500 / 600。组头 13sp 600 次要色。

## 4. 形状与间距

- 圆角只用：`8`（行内代码、小标签）、`12`（输入框、代码块、选项框）、`16`（横幅、状态槽、输入区、容器块）、`28`（弹层顶角、对话框）、全圆（按钮、chip、FAB、头像）。
- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32。页面左右边距 20（列表行 16 起，文字对齐 20）。
- 列表行高：单行 52、双行 64；触控区域 ≥ 48dp。
- 不用阴影（elevation = 0）。弹层与对话框用 scrim 区分层级。

## 5. 组件（基础组件，位于 `native/ui/v4/`）

`DlTopBar` · `DlListRow` · `DlSectionHeader` · `DlStatusSlot` · `DlInboxItem` · `DlComposer` · `DlDecisionBar` · `DlBottomSheet` · `DlDialog` · `DlChip` / `DlSegmented` · `DlWorkspaceRow`

首页 2.1–2.3 按工作区文件夹分组，`DlWorkspaceRow` 提供展开和独立新建入口；`DlInboxItem` 的紧凑模式用于缩进会话，底部搜索与新建组合已有列表行和图标按钮。折叠行保留待处理 / 运行计数，展开状态按主机保存。

页面文件不得直接用 M3 的 `Card` / `ElevatedCard` / 带 tonalElevation 的 `Surface`，也不得自己画顶栏或输入区。需要新组件时，先改本文件和设计稿，再写代码。

## 6. 页面语法

1. **顶栏**：返回/关闭 + 标题 + 可选副标题 + 最多 2 个动作。对话页额外允许一个 diff 角标。
2. **状态槽**（对话页顶栏下方）：同一时间只显示一个状态，优先级：断线 > 待处理 > 目标 > 预览。平时一行，点开展开。
3. **过程**：思考、工具调用默认收成一行灰字（`思考 6 秒 · 读了 4 个文件 ›`），展开后是细线串起的步骤，不做卡片。
4. **决策**：审批和提问不进消息流，用 `DlDecisionBar` 替换输入区。主操作在右、品牌实心；次操作在左、容器色。
5. **轮尾**：改动文件 → 元信息灰字 → 文字按钮 → 建议 chip，顺序固定。
6. **弹层**：`DlBottomSheet` 不叠第二层 sheet；需要二次确认用 `DlDialog`。危险操作只用红色文字，不用红色实心按钮，放在最后或左侧。
7. **列表页**（设置等）：平铺列表 + 组头，不用白卡；整页最多一个容器色块（如当前电脑）。
8. **空态**：图标 + 一句话 + 下一步（一个按钮或几条列表行）。
9. **离线 / 失败**：中性底横幅，只有图标用状态色。

## 7. 动效

- 只用 M3 默认过渡与 `DshDuration` / `DshEasing` 的 3 档（短 / 中 / 长）。系统“减少动态效果”开启时全部跳过。
- 不做弹簧、视差、折射、高光扫过。

## 8. 禁止清单

`Modifier.blur`、`RenderEffect`、半透明背景（alpha < 1 的面，scrim 除外）、渐隐遮罩、阴影、渐变、品牌字体、动态取色、按名字配色、同屏两个品牌实心按钮、弹层叠弹层、消息流内的审批卡。
